# Jeniffer Lopes — Nail Design Studio

Site estático, sem dependências ou backend. A direção visual atual combina fundo escuro, rosa vivo e molduras inspiradas em câmeras digitais retrô. Botões, links, filtros, cartões e blocos de conteúdo têm transições e microanimações; a preferência do sistema por movimento reduzido é respeitada. Abra `index.html` em um navegador para visualizar localmente. Para publicar, envie a pasta inteira para uma hospedagem de páginas estáticas.

## Ajustes de conteúdo

Edite `site-config.js` para atualizar o nome, WhatsApp, Instagram, localização, serviços, fotos, avaliações e dúvidas. O telefone está vazio de propósito: enquanto não houver um número em formato internacional, o site mostra o contato direto pelo Instagram e oculta o formulário de WhatsApp. Ao cadastrar o número, o formulário aparece e prepara a solicitação para envio pelo WhatsApp.

As imagens de unhas foram recortadas da captura de tela mais recente enviada. Os recortes preservam o máximo de detalhe disponível e cabem bem na galeria; os arquivos originais das fotos permitiriam uma visualização ampliada ainda mais nítida. As respostas sobre procedimentos devem ser revisadas pela profissional. Os textos atuais evitam afirmar duração, preço ou resultados não confirmados.

## Publicação e busca

O endereço comercial fornecido está no conteúdo e nos dados estruturados. Configure o domínio final, atualize `og:image` para uma URL absoluta e publique um sitemap com a URL canônica depois de escolher a hospedagem. As fotos da pasta `assets` foram recortadas das referências compartilhadas para uso na apresentação do portfólio; substitua pelas imagens originais em alta resolução quando disponíveis.

## Contato e disponibilidade

O formulário apenas prepara uma solicitação e abre o WhatsApp quando o número estiver configurado. Ele não consulta agenda, confirma horários nem automatiza mensagens recebidas. Esses recursos exigem integração externa e backend.
